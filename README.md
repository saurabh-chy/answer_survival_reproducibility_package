# Reproducibility package: The Complexity of Query-Answer Survival under Correlated Data Loss

Saurabh Choudhary, Sachin Malhotra, Janarthanan Midhunchakkaravarthy, Rajanish Kumar Jain

This package reproduces every empirical result of the paper: data generation, all experiments,
Tables 3–9, Figures 1–2, and the extended Tables S1–S9 of the supplementary document.

## Contents

| File | Description |
| --- | --- |
| `S1_reproducibility_notebook.ipynb` | **Main file.** Self-contained notebook: installs dependencies, generates the TPC-H data, runs every experiment, draws both figures and writes all result files. Delivered with the outputs of the reported run. |
| `make_figures.py` | Stand-alone script that redraws Figures 1 and 2 from the result files (optional; the notebook already draws them) |
| `requirements.txt` | Package versions of the reported run |
| `results/` | Result files and figures of the reported run (same names as listed under *Output files*) |
| `README.md` | This file |

## Requirements

- Python 3.10 or later
- Packages: `duckdb`, `numpy`, `sympy`, `matplotlib`, `tpchgen-cli` (installed by the first cell of the notebook; versions in `requirements.txt`)
- About 300 MB of free disk space for the generated TPC-H data
- At least 4 GB of RAM; no GPU is required

## Running in Google Colab

1. Open <https://colab.research.google.com> and choose **File → Upload notebook**.
2. Select `S1_reproducibility_notebook.ipynb`.
3. Choose **Runtime → Run all**.
4. When prompted, allow access to Google Drive. All outputs are written to `MyDrive/answer_survival`.

## Running locally

```bash
pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --ExecutePreprocessor.timeout=-1 S1_reproducibility_notebook.ipynb
```

Outputs are written to `answer_survival_output/` next to the notebook. A complete run takes about 13 minutes on a
two-core machine.

## Reproducibility notes

- **Seeds:** 20261106 (Section 9.2), 7 (Monte Carlo, re-initialised for each scale factor and query; Python random
  seed 7 also selects the 200 Monte Carlo customers of Q2), 1 (sampling of answer pairs in the crossing study),
  11 (dense sharing).
- Exact values, bounds, crossing counts and both figures are deterministic. Monte Carlo values are reproduced exactly
  when the seeds and the processing order of nations and customers are unchanged.
- For Q2 the exact baseline is computed for customers with at most 18 (SF 0.01) or 16 (SF 0.1 and SF 1) shared
  supplier units; at SF 0.01 this excludes 246 of the 1,000 customers that have orders.
- Running times depend on the hardware; times are comparable only within a table.
- TPC-H data are generated with `tpchgen-cli` 4.0.0, an open-source reimplementation of the TPC-H dbgen generator.
  Queries are adapted to set semantics; the results are not official TPC-H results.
